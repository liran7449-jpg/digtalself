# 《数字人生》V1.1 开发需求文档

## Today + Moments Refinement & Me V1.0

> 版本：V1.1\
> 当前已完成：Today、Moments\
> 下一阶段：优化 Today / Moments，建立 Moment 数据关联能力，并开发 Me
> V1.0\
> 核心目标：让产品从"漂亮的个人记录工具"开始成为"会逐渐理解我的数字人生"。

------------------------------------------------------------------------

# 1. 本阶段目标

当前产品已经完成 Today 与 Moments 两个核心页面，视觉方向已经形成：

> Quiet Luxury + Personal + Alive

本阶段不推倒重做，而是围绕现有产品继续迭代。

核心目标：

1.  优化 Today，但保持当前信息结构。
2.  让 Moments 从"文字记录列表"逐渐成为"生活记忆流"。
3.  建立 Moment 与 Day / Person / Place / Goal / Memory 等对象的关系。
4.  开发 Me V1.0，让用户开始回答"我是谁、我在乎什么、我想成为谁"。
5.  暂时不引入 AI，把真实数据和数据关系先做好，为未来 AI Memory 打基础。

------------------------------------------------------------------------

# 3. 重要产品决策

## 3.1 暂时不区分 Today State 和 Today's Focus

保持当前结构：

``` text
Good evening.

● Low · Low energy

TODAY'S FOCUS

工作太多了
```

不要增加一个新的 `Today State` 模块。

原因：

当前产品仍处于早期阶段，Today 应该保持非常简单。Mood / Energy
已经能够表达状态，Today's Focus 继续承担"今天最重要的事情 /
当前关注点"的作用即可。

------------------------------------------------------------------------

## 3.2 删除 4/10，但保留 YOUR DAY

删除：

``` text
YOUR DAY    4/10
```

修改为：

``` text
YOUR DAY
```

`YOUR DAY` 不删除。

它代表：

> 今天真实发生过的一切。

未来可以包含：

-   今日计划
-   完成 / 未完成事项
-   Moments
-   Mood
-   Energy
-   People
-   Memories

不要给一天做简单的 1--10 分评分，避免产品变成"生活效率评分器"。

# 9. Moment 类型

本阶段定义：

  Type      含义
  --------- --------------------------
  Thought   突然产生的想法
  Diary     较完整的日记
  Photo     图片
  Event     发生的一件事情
  Person    与某个人有关
  Place     与某个地点有关
  Idea      值得继续思考的想法
  Memory    被认为值得长期保存的内容

第一阶段重点实现：

> Thought + Photo + Event + Person / Place 基础关联

不要求一次全部做完。

# 10. Moment Detail

点击 Moment 后进入详情。

建议：

``` text
September 8, 2026
20:35

好想她……

THOUGHT

────────────────

People
某人

Place
北京

Related
相关目标 / 主题

────────────────

```

原则：

-   关联信息全部可选。
-   没有关联数据时不显示空模块。
-   用户可以后续编辑。
-   不要求创建 Moment 时填写所有字段。

# 11. Moment 关系模型

这是本阶段最重要的底层能力。

一个 Moment 可以关联：

``` text
Moment
├── Day
├── Person
├── Place
├── Goal
├── Topic
└── Memory
```

例如：

``` text
Moment
“北京天气很好，但是爱的人不在身边。”

        ↓

Person
某人

Place
北京

Topic
关系 / 想念

Memory
可选
```

核心原则：

> **一件事情只记录一次，但可以在整个数字人生中流动。**

未来同一条 Moment 可以被：

-   Moments
-   People
-   Journey
-   Me
-   AI Butler

重新引用。

# 18. About Me

> 我是谁。

-   一句话
-   一段文字
-   几个关键词

``` text

```

> User-authored Identity

AI 未来可以提出建议，但不能覆盖用户自己写下的身份描述。


# 26. AI 暂时不引入

当前阶段：

> **不开发 AI。**

先做好：

``` text

 ↓
关系
 ↓
记录
 ↓
展示
```

AI 后续建立在真实数据之上。

未来 AI 的三个核心能力：

### Plan

帮我规划今天。

### Reflect

帮我理解今天。

### Remember

帮我记住重要的东西。

更长期再扩展：

### Understand

帮我理解自己。

# 31. Vibe Coding 开发 Sprint

### 开发

1.  删除 `4/10`

# 33. 本阶段成功标准

不是：

> 页面越多越好。

不是：

> 功能越丰富越好。

不是：

> AI 越智能越好。

而是：

> **我愿意把真实生活继续放进这里。**

并且：

> **我相信这些记录以后会变得有价值。**

最终形成：

``` text
今天
 ↓
我记录了一点东西
 ↓
它成为我的 Moment
 ↓
Moment 与我的生活发生关系
 ↓
慢慢形成 Memory
 ↓
慢慢形成 Growth Evidence
 ↓
最终让我看到
 ↓
WHO I'M BECOMING
```
